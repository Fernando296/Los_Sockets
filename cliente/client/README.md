# Los Sockets - Frontend

Este es el cliente del proyecto **Los Sockets**, una aplicación de chat colaborativo en tiempo real construida con React y Vite.

## Tecnologías

- **React**: Biblioteca de JavaScript para construir interfaces de usuario.
- **Vite**: Herramienta de construcción ultrarrápida para proyectos web modernos.
- **Prettier**: Formateador de código para mantener la consistencia.
- **WebSockets**: Protocolo de comunicación en tiempo real.

## Configuración

Para ejecutar este proyecto localmente:

1. Asegúrate de tener instalado [Node.js](https://nodejs.org/).
2. Navega a esta carpeta: `cd cliente/client`.
3. Instala las dependencias: `npm install`.
4. Inicia el servidor de desarrollo: `npm run dev`.

## Scripts Disponibles

- `npm run dev`: Inicia el servidor de desarrollo de Vite.
- `npm run build`: Construye la aplicación para producción.
- `npm run lint`: Ejecuta ESLint para encontrar problemas en el código.
- `npm run preview`: Sirve la versión de producción localmente.
